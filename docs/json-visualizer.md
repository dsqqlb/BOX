# JSON 星系

路径：`/tools/json-visualizer`
所需权限：`json-visualizer`

JSON 星系用于校验、格式化、压缩和探索 JSON 数据，并将结构映射为可交互的 3D 星系。

## 使用

1. 在编辑器粘贴有效 JSON。
2. 使用格式化、压缩或复制操作整理文本。
3. 执行可视化/解析后，在 3D 视图中查看对象、数组和字段节点。
4. 选择节点可查看其关联内容；可使用侧栏和行宽控制调整浏览体验。

输入必须是合法 JSON；语法错误会在解析时提示，修正后再运行即可。

## 数据与隐私

解析、格式化、压缩和 3D 渲染都在浏览器客户端完成。工具不会把 JSON 内容发送到 BOX 的业务 API；仍应避免在任何共享设备的页面中粘贴敏感数据。

## 适用范围

该工具用于理解 JSON 的结构与层级，不会修改源文件或替代 JSON Schema 校验。对于非常大的文本，3D 节点数量会增加，浏览器渲染可能变慢；可先缩小输入范围。
