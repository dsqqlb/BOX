# 德州扑克

路径：`/tools/texas-holdem`。需要 `texas-holdem` 工具权限。无限注德州扑克，可开房联机，也可以叫机器人陪打。

**筹码是纯娱乐虚拟币，与真实货币无关，也不支持任何形式的兑换。**

## 玩法流程

1. **大厅**：查看自己的筹码余额、筹码流水，创建牌桌或用 6 位房间号加入别人的牌桌。
2. **建房**：房主决定小盲注、大盲注、买入筹码、座位数（2–6 人）和每次思考时长（10 / 15 / 30 秒）。建房即从账户余额扣除买入。
3. **等待室**：房主可以任意添加/移除机器人（新手、普通、高手三档）。桌上有筹码的玩家满 2 人后，房主可随时开局。
4. **牌局**：翻牌前 → 翻牌 → 转牌 → 河牌 → 摊牌。一手结束后 6 秒自动开下一手；有筹码的玩家不足 2 人时自动回到等待中。
5. **离桌**：普通玩家离桌会把桌上剩余筹码退回账户；房主离桌等于解散房间，所有真人玩家的桌上筹码都会退回各自账户。

## 服务端权威

发牌、下注合法性、最小加注额、全下、边池切分和摊牌比牌全部由服务端裁定，客户端只发送动作意图：

- 牌堆用 `crypto.randomInt` 做无偏 Fisher-Yates 洗牌，牌堆永不下发给浏览器。
- **别人的底牌在摊牌前不会下发到任何客户端**：每个连接只收到自己视角的状态（`server/holdem-engine.js` 的 `handView`）。
- 牌型判定使用 [pokersolver](https://github.com/goldfire/pokersolver)（MIT 许可，已固定为 2.1.4）。
- 边池按每位玩家的实际投入分层切分，短筹码玩家最多只能赢到自己投入所覆盖的那部分；无法整除的零头按座位顺序分配，保证底池总额守恒。

## 机器人与超时托管

机器人用蒙特卡洛模拟估算胜率，再与底池赔率比较决定弃牌、跟注还是加注，三档难度在模拟次数、跟注松紧、加注门槛和诈唬频率上不同（`server/holdem-bots.js`）。

思考超时后由机器人**接管这一次决策**（保守策略：不主动加注，牌力不够就过牌或弃牌），界面会显示「托管中」；玩家下一次自己行动即收回控制权。玩家掉线期间也由机器人代打，避免整桌卡住。

## 筹码账户

| 表 | 用途 |
| --- | --- |
| `HoldemBalance` | 每账户一行的可变余额，含累计手数与胜场 |
| `HoldemLedger` | 追加式流水，记录每次变动的金额、变动后余额、类型与房间号 |

余额只在**买入上桌**和**离桌结算**两个时刻变动，牌局进行中的下注只存在于内存房间里。所有变动都在一个 SQLite 事务内完成，并强制余额不为负；余额不足的买入会返回 409。

新账户首次打开工具时赠送 `HOLDEM_STARTING_CHIPS`（默认 10000，可用环境变量覆盖，范围 1000–10000000）。余额低于最小买入（100）时，可在大厅点「补充筹码」自助恢复到初始值，补充同样写入流水。

## 接口与实时通道

| 方法与路径 | 说明 |
| --- | --- |
| `GET /api/holdem/account` | 读取余额与统计，首次调用会开户并赠送初始筹码 |
| `POST /api/holdem/account` | 请求体 `{ "action": "reset" }`，余额不足时自助补充 |
| `GET /api/holdem/ledger` | 最近 50 条筹码流水 |
| `GET /api/holdem/rooms` | 大厅房间列表，只含公共信息，不含任何手牌 |

牌局本身走 WebSocket `/ws?holdem=1`（与先攻追踪器、Kards 复用同一个 `/ws` 路径，便于反向代理只转发一个路径）。升级请求会校验同源、登录状态和 `texas-holdem` 权限，并在每条消息上重新校验权限，因此权限被移除后已建立的连接会立即失效。

客户端消息：`PING`、`CREATE_ROOM`、`JOIN_ROOM`、`ADD_BOT`、`REMOVE_BOT`、`START_GAME`、`ACTION`、`REBUY`、`LEAVE_ROOM`、`DELETE_ROOM`。
服务端消息：`ROOM_STATE`（按座位裁剪）、`ROOM_CLOSED`、`ERROR`、`PONG`。

## 已知限制

房间状态保存在进程内存中（与其他房间类工具一致），**服务重启会清空所有牌桌**。因为桌上筹码要等离桌才回账，进程异常退出时进行中的一手连同桌上筹码会一并丢失，已扣除的买入不会自动退回。正常使用「离桌结算」或由房主解散房间都会正确回账；闲置 2 小时的房间会被自动回收并退回筹码。

界面为自绘 SVG：筹码 7 档面额（1/5/25/100/500/1000/5000）、扑克牌面与暗牌均为矢量绘制，无外部素材依赖。加注时可以逐枚点击筹码累加金额，也可以用滑块或半池/一池/全下快捷键。
