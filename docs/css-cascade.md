# CSS 层叠解释器

路径：`/tools/css-cascade`
所需权限：`css-cascade`

CSS 层叠解释器使用 `css-tree` 解析输入的 CSS，并把规则、嵌套上下文和特异性组织为可浏览的层叠视图。

## 使用

1. 粘贴 CSS 后点击“解释”触发解析。
2. 在规则视图中查看选择器、声明、`!important`、特异性和来源位置。
3. 通过筛选、画廊/轨道视图和源码高亮定位相关规则。
4. 展开 `@media`、层或其他 at-rule 上下文，理解规则所处的条件。

语法错误会在解析时显示；修复输入后再次执行解释即可。

## 范围

工具解释的是已解析 CSS 的结构和优先级线索，不会加载网页 DOM、执行浏览器样式计算或保证某个元素的最终渲染结果。实际 CSS 结果还会受元素匹配、继承、浏览器默认样式、运行时样式和媒体条件影响。

所有解析与可视化都在浏览器客户端进行，输入不会提交到 BOX 的业务 API。
