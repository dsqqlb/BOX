# 塔罗牌占卜

路径：`/tools/tarot-reading`
所需权限：`tarot-reading`

塔罗工具提供 78 张牌的互动洗牌、抽牌和牌义查看体验，适合娱乐、记录感受和自我反思。

## 牌阵

- 单张牌
- 三张牌
- 情况 / 行动 / 结果
- 凯尔特十字

选择牌阵后进入洗牌与发牌流程。每张抽出的牌独立决定正位或逆位，点击结果中的牌可查看详情与对应牌义。

## 注意事项

- 抽牌是随机的，结果不构成医疗、法律、财务或其他专业建议。
- 阅读内容应作为反思和娱乐的素材，而不是替代个人判断或专业帮助。
- 牌组数据和交互状态在客户端使用；牌面图片资源仍受 `tarot-reading` 工具权限保护。

## 资源维护

牌组信息来自项目的塔罗数据文件，牌面资源位于 `public/image/tarot/`。新增或替换资源时，应保持数据中的标识与图片路径对应，并在具有该工具权限的账户下检查图片能否正常显示。
