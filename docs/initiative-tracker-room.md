# DND 先攻追踪器

控制端路径：`/tools/initiative-tracker`
主屏路径：`/tools/initiative-tracker/display`
所需权限：`initiative-tracker`（该权限包含主屏）

先攻追踪器由同源 WebSocket `/ws` 实时同步。它不使用旧版 localStorage 轮询；登录和工具权限会在连接 WebSocket 前由服务端校验。

## 快速开始

1. DM 在主屏页面创建一个六位数房间，或从仍在活动的房间中选择一个。
2. 主屏显示房间号和加入二维码。
3. 玩家或 DM 在控制端输入房间号并连接。
4. 在控制端创建角色、将角色加入战斗、设置先攻并开始回合。

主屏会实时显示角色卡、当前回合、状态效果和共享骰子记录。控制端用于管理角色、回合、骰子表达式/预设与显示外观。

## 房间规则与数据边界

- 房间号用于协作，不是独立的授权机制。拥有先攻追踪器权限的账户可以参与允许访问的房间。
- 主屏归属到创建它的账户；只有该账户可以重新作为该房间的主屏接管连接。
- 战斗房间、角色、回合和骰子历史保存在服务进程内存中。服务重启会清空它们。
- 无主屏或控制端连接的房间会在空闲一小时后自动清理；仍有客户端连接时不会被此清理任务删除。
- 控制端的备选角色池、部分外观和预设等浏览器偏好保存在 localStorage；清除浏览器数据会移除这些本地设置。

## 主要操作

### 角色与回合

在控制端创建玩家、敌人或 NPC 角色，加入/移出战斗并调整先攻顺序。可控制前进、回退和回合结束；角色支持状态效果展示。

### 骰子

控制端支持常用骰子和表达式、预设及外观设置。投骰结果会同步到主屏历史；主屏会显示 3D 骰子、保留高/低（`kh`/`kl`）等结果及自然 1/20 的视觉效果。

### 主屏

主屏适合投影：可创建或选择房间，展示战斗卡片、回合、状态、骰子和二维码。二维码当前指向部署时配置的固定公开地址；在局域网或自定义域名使用时，建议直接输入控制端地址与房间号，或确认二维码链接是否适用。

## 排错

- **无法连接房间**：确认两端已登录、账户有 `initiative-tracker` 权限、房间号一致，且浏览器能够建立同源 `/ws` 连接。
- **刷新后房间不见**：检查服务是否重启，或房间是否在所有客户端断开后空闲超过一小时。
- **只能看到部分功能**：重新登录并检查 `data/auth-users.json` 中的权限；权限变更会在后续请求中生效。
