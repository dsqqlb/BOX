# DND 先攻追踪器 - 房间模式使用指南

## 🎮 系统架构

**主屏 + 多遥控器** 的协作模式，专为桌面DND游戏设计。

### 📺 主屏幕（Display）
- **用途**：投影到大电视/投影仪，所有人都能看到
- **功能**：实时显示所有角色、当前回合、回合数
- **风格**：博德之门3风格的炫酷卡片
- **地址**：`/tools/initiative-tracker/display`

### 🎛️ 遥控器（Controller）
- **用途**：每个玩家用自己的设备（手机/平板/电脑）
- **功能**：管理自己的角色池、拖拽角色到战斗区
- **地址**：`/tools/initiative-tracker`

---

## 🚀 快速开始

### 步骤1：DM开启主屏
1. 打开浏览器访问：`http://localhost:3000/tools/initiative-tracker/display`
2. 页面自动生成6位数字房间号（例如：`123456`）
3. 投影到大屏幕
4. 告诉玩家房间号

### 步骤2：玩家连接遥控器
1. 每个玩家打开：`http://localhost:3000/tools/initiative-tracker`
2. 输入DM提供的房间号（例如：`123456`）
3. 点击"连接房间"

### 步骤3：创建角色
1. 在遥控器中点击"➕ 自定义角色"
2. 选择类型：
   - **👤 玩家**：选择种族+职业（有像素风图片）
   - **👹 敌人**：搜索怪物图片
   - **🧔 NPC**：可选玩家图片或怪物图片
3. 输入角色名称
4. 点击"✓ 添加角色"

### 步骤4：进入战斗
1. 从备选区拖动角色到战斗区
2. 拖动到刻度尺上设置先攻值
3. 角色会自动出现在主屏上（带动画效果✨）

### 步骤5：战斗！
- 主屏显示当前回合（超强光效高亮）
- 轮到自己时，遥控器上会显示"✓ 结束我的回合"按钮
- 点击按钮，自动切换到下一个角色
- 所有人都能看到实时更新

## 🎯 核心功能

### ⚔️ 回合控制
- **结束我的回合**：只有当前回合的玩家能按（高亮显示）
- **上一个/下一个**：所有人都能按，防止有人掉线

### 🎨 视觉效果
- **博德之门3风格卡片**：精美的角色卡片设计
- **当前回合超强光效**：多层光圈+旋转边框
- **角色进场动画**：从下方滑入并放大
- **角色退场动画**：向上滑出并缩小

### 🔄 实时同步
- 所有遥控器和主屏通过localStorage实时同步（200ms）
- 任何人的操作都会立即反映到主屏
- 支持多人同时上传角色

### 📦 角色归属
- 每个角色标记归属（ownerId）
- 只能管理自己创建的角色
- 可以看到所有人的角色

## 🎪 使用场景

### 典型桌面DND游戏
```
        📺 大屏幕（主屏）
```

## 🛠️ 技术细节

### 房间ID
- 6位纯数字（100000-999999）
- 主屏自动生成
- 遥控器输入连接

### 遥控器ID
- 自动生成唯一ID（格式：`Cxxxxxxxxx`）
- 存储在localStorage
- 用于标识角色归属

### 数据同步
```javascript
// 房间数据结构
{
  roomId: "123456",
  characters: [...],  // 所有角色
  currentTurn: 0,     // 当前回合索引
  roundNumber: 1      // 回合数
}

// 存储键：initiative-room-{roomId}
localStorage.setItem('initiative-room-123456', JSON.stringify(roomData))
```

### 同步频率
- 遥控器 → 主屏：200ms轮询
- 主屏实时显示
- 操作立即生效

## 💡 使用技巧

### 1. 防掉线机制
- 如果当前回合的玩家掉线了
- 任何人都可以点"下一个"强制前进
- 或点"上一个"回退

### 2. 多角色管理
- 一个遥控器可以管理多个角色
- DM可以同时控制多个怪物
- 玩家可以创建多个角色

### 3. 先攻值调整
- 战斗中也可以拖动调整先攻
- 如果先攻值重叠，会弹窗排序
- 通过小数位区分顺序（15.02, 15.01, 15.00）

### 4. 角色移除
- 从战斗区拖回备选区 = 移除
- 主屏上该角色会播放退场动画
- 不会删除角色，只是移出战斗

### 5. 本地模式
- 不需要房间也能单机使用
- 适合单人练习或测试
- 数据保存在本地

## 🔧 故障排除

### Q: 房间连接后看不到其他人的角色？
A: 检查房间号是否一致，刷新页面重新连接

### Q: 主屏不更新？
A: localStorage可能被清空，所有人重新连接

### Q: 角色消失了？
A: 可能被其他人移除，检查备选区或重新添加

### Q: "结束我的回合"按钮不显示？
A: 当前不是你的角色回合，等轮到你时会自动显示
