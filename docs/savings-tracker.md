# 省钱网页

路径：`/tools/savings-tracker`
所需权限：`savings-tracker`

省钱网页用于记录“本来想花、但最终省下”的金额，并按当前登录账户展示记录和统计。

## 使用

- 新增记录时填写日期、时间、活动、物品和金额。
- 可编辑或删除自己的记录。
- 页面提供累计、周/月范围等汇总视图，以及表单预设和明暗主题。

## 持久化与隔离

记录通过受保护的 `/api/savings` 写入 `data/savings.json`。服务端为每条记录写入登录用户名，读取、编辑和删除时只返回该账户自己的数据；一个账户不能通过页面访问另一账户的记录。

表单预设和主题属于浏览器 localStorage，只在当前浏览器可见；省钱记录本身保存在服务端数据文件中。

## 运行维护

生产运行时 `data/` 必须可写，且应将 `data/savings.json` 纳入常规备份。手动迁移或编辑该文件前先停止服务并备份：旧版没有 `owner` 字段的记录不会自动显示给任何账户，以避免意外泄露。

金额记录仅用于个人整理，不替代财务、税务或投资建议。
