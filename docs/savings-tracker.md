# 省钱网页

路径：`/tools/savings-tracker`
所需权限：`savings-tracker`

省钱网页用于记录“本来想花、但最终省下”的金额，并按当前登录账户展示记录和统计。

## 使用

- 新增记录时填写日期、时间、活动、物品和金额。
- 可编辑或删除自己的记录。
- 页面提供累计、周/月范围等汇总视图，以及表单预设和明暗主题。

## 持久化与隔离

记录通过受保护的 `/api/savings` 直接写入 SQLite。服务端按登录账户关联记录，读取、编辑和删除时只返回该账户自己的数据；一个账户不能通过页面访问另一账户的记录。

表单预设和主题属于浏览器 localStorage，只在当前浏览器可见；省钱记录本身保存在服务端 SQLite 数据库中。

## 运行维护

生产运行时 `data/` 必须可写，并应将 `data/box.sqlite` 纳入常规备份。旧版 `data/savings.json` 可用 `npm run db:migrate-runtime-json` 一次性导入；脚本会先备份源文件，且不会自动归属或暴露没有有效 `owner` 的旧记录。

金额记录仅用于个人整理，不替代财务、税务或投资建议。
