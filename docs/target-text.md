# 目标大屏

- 路径：`/tools/target-text`
- 权限：`target-text`
- 持久化：无服务端持久化。编辑器通过 URL 查询参数生成投屏配置；展示文本请避免包含私密内容。

## 用途

将一句关键文字转换为适合电视、投影、活动屏、会议室或门店屏幕的醒目展示。编辑器提供实时预览，并能打开一个没有控制面板的独立投屏页。

## 配置功能

- 单行展示文字，最长 240 个字符
- 静止、向左/右/上/下滚动，以及呼吸脉冲
- 动画周期、字号、左中右对齐
- 四种字体：现代无衬线、庄重衬线、终端等宽、海报粗体
- 文字与背景颜色、文字光晕、闪烁警示
- 倒计时与右下角当前时间
- 目标宣言、紧急提醒、欢迎横幅、倒计时、深度专注预设

## 投屏与快捷键

点击“打开投屏页”会在新标签页中打开带有 `present=1` 的纯净展示模式。该 URL 带有 `text`、`motion`、`font`、`size`、`speed`、色彩等展示参数，可复制后在投影设备上打开。

投屏页按 `F` 可请求浏览器原生全屏，按 `Esc` 退出全屏。URL 参数适用于短展示文本，可能出现在浏览器历史或复制的链接中，因此不要使用它展示密码、身份信息或其他敏感内容。
