# UNO 联机牌桌

路径：`/tools/uno`。需要 `uno` 工具权限。

**当前状态：分步开发中。**规则引擎、机器人、房间联机、界面与育碧风格牌桌美术（Step 1–4）已完成并通过自测；牌库一览、动效与音效、拖拽出牌、设置页面、拓展包尚未实现。

## 界面（Step 3）

| 环节 | 现在能做什么 |
| --- | --- |
| 大厅 | 看正在等待的房间（房号、房主、人数、思考时间、房规摘要）；点「加入」或直接输 6 位房间号；建房前可定座位数、思考时间、逐条房规、机器人数量与难度 |
| 等待室 | 复制房间号；邀请链接 `/tools/uno?room=123456` 会自动预填房号；房主可加/移除机器人、改设置、随时开局；其他玩家看到「等房主开始」 |
| 牌桌 | 点手牌即出（可出的牌有高亮；万能牌先弹选色盘）；抓一张 / 过牌 / 喊 UNO；别人忘喊 UNO 时座位旁出现举报按钮；托管与收回；倒计时；对局日志；结束后房主可「再来一局」 |
| 断线与托管 | 掉线不清座位、不丢手牌；思考超时或掉线后由机器人接手，回来点「收回」即可继续 |

## 房间规则

- 任何有 `uno` 权限的账户都能建房，房间号是 6 位数字，建房者坐在 0 号位并成为房主。
- 房主在**等待中**可以随时改设置：座位数 2–4、思考时间（10/20/30 秒或不限时）、房规开关、拓展包（Step 7 落地）。
- 房主可以加/移除机器人；占座满 2 人（含机器人）即可开局。开局后房主点「再来一局」可重新发牌。
- **座位归账户所有**：掉线不清座位、不退手牌。掉线、思考超时、主动点「托管」都只是让机器人接着打，
  玩家重新加入同一房间即自动收回控制权（手牌与进度原样保留）。
- 房主主动离开会把房主身份顺延给最早加入的真人；没有真人留下时房间直接解散。
- 闲置回收（可用环境变量调小，便于测试）：等待中 30 分钟没人进入、对局中 15 分钟没人操作、全员掉线 5 分钟。

## 接口与实时通道

| 方法与路径 | 说明 |
| --- | --- |
| `GET /api/uno/ping` | 连通性自检，回显账户名与权限判定 |
| `GET /api/uno/rooms` | 大厅房间列表：房间号、人数、房规摘要、思考时间；不含任何手牌 |
| `GET /api/uno/catalog` | 牌组目录：颜色、牌型（含说明与使用技巧）、房规说明、思考时间档位与人数上限 |

牌局走 WebSocket `/ws?uno=1`。升级请求会校验同源、登录状态与 `uno` 权限，并且每条消息都会重新校验权限，
因此权限被移除后已建立的连接会立即失效。

客户端消息：`PING`、`CREATE_ROOM`、`JOIN_ROOM`、`LEAVE_ROOM`、`DELETE_ROOM`、`UPDATE_SETTINGS`、
`ADD_BOT`、`REMOVE_BOT`、`START_GAME`、`REMATCH`、`PLAY_CARD`、`DRAW_CARD`、`PASS`、
`CHOOSE_COLOR`、`CALL_UNO`、`CHALLENGE_UNO`、`SET_AUTO_PILOT`。

服务端消息：`ROOM_STATE`（自己视角的快照 + 本次新增的事件，事件用于客户端播放动画）、`ROOM_CLOSED`、`ERROR`、`PONG`。

## 已知限制

房间状态保存在进程内存中（与其他房间类工具一致），**服务重启会清空所有房间**。

## 已实现的房规（建房时可逐项开关，默认值见括号）

| 选项 | 说明 | 默认 |
| --- | --- | --- |
| 罚牌叠加 | +2 只能用 +2 接、+4 只能用 +4 接，罚牌累加给接不住的人 | 关 |
| +4 执法 | 只有手上没有当前颜色时才能打 +4 | 关 |
| 摸到能出为止 | 抓牌抓到有能出的牌为止，而不是只抓一张 | 关 |
| 摸到必出 | 抓到的牌能出就必须出 | 关 |
| 喊 UNO | 剩最后一张要喊，否则被举报罚摸两张（诬告者罚摸一张） | 开 |
| 首张牌生效 | 开局翻出的功能牌效果直接作用在第一位玩家身上 | 开 |

其他固定规则：双人局里反转牌等同禁止牌；抓完牌后这一轮只能打出刚抓到的那张（否则过牌）；牌堆用尽时把弃牌堆（留顶牌）洗回牌堆；万能用牌打出后必须先指定颜色，颜色定了才轮到下一位。

## 计划中的设计（尚未实现）

以下内容已与需求方确认，但**代码还没写**，仅作实现路线记录：

1. **房间**：6 位房间号，任何人都能建房；大厅可看房间列表；等待中 30 分钟没人进入、对局中 15 分钟无操作、全员掉线 5 分钟会被回收。
2. **房主自定义**：座位数 2–4、机器人数量与难度、启用哪些拓展包、玩法规格、思考时间档位（10/20/30 秒与无限）。
3. **托管与席位找回**：思考超时或掉线超过思考时间后由机器人接管该座位；玩家可主动点「托管」；回来（重连或点「收回」）即可顶替回机器人，手牌与进度原样保留。
4. **拖拽出牌与动效**：出牌同时支持「拖拽到弃牌堆」与「单击直接出牌」；发牌 / 出牌 / 抓牌的飞行动效与音效（静态美术已在 Step 4 完成，见上文「美术」）。
5. **牌库一览**：从主页进入的卡牌图鉴，按分类浏览每一张牌（含拓展牌），鼠标悬停或移动端点击弹出浮层详情，带动效。
6. **设置页面**：操作方式、桌面显示、对局默认值、托管与断线、账号显示等分组设置（偏好存浏览器 `localStorage`）。
7. **拓展系统**：拓展包用 JSON 描述「新牌 + 参数 + 房规开关」，前端零改动自动渲染；全新玩法由 `code/server/uno-hooks/<id>.js` 里的钩子实现，引擎在回合开始、出牌前后、摸牌后、结算等阶段调用。
