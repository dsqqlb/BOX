# DND 语言翻译器

路径：`/tools/dnd-translator`
所需权限：`dnd-translator`

将中文或英文文本翻译为另一种语言，并用奇幻字体展示对应的符文效果。

## 功能

- 中英文双向翻译。
- 使用 Davek、Magi、Elvish 三种字体展示符文文本。
- 可选择需要显示的语言卡片。
- 可将符文内容导出为 PNG，并调整导出样式。
- 输入内容和语言选择保存在当前浏览器的 localStorage 中。

## 使用说明

1. 输入中文或英文，并选择源语言与目标语言。
2. 执行翻译后，在下方查看普通文本与符文字体效果。
3. 按需要启用或关闭语言卡片；在导出面板中设置颜色、字号、背景和边距后导出 PNG。

## 隐私与网络

翻译请求由浏览器直接发送给 MyMemory 公共翻译服务。输入的文本会离开本应用并受该第三方服务的可用性、限流和隐私规则约束；请勿输入密码、个人隐私或其他敏感内容。符文字体展示和导出在浏览器本地完成。

## 维护字体

字体文件位于 `public/fonts/`，并通过 `app/globals.css` 中的 `@font-face` 声明。新增一种字体时：

1. 将合法授权的字体文件加入 `public/fonts/`。
2. 在 `app/globals.css` 注册字体。
3. 在 `app/tools/dnd-translator/page.tsx` 的语言配置中添加对应条目。

完成后检查页面显示和 PNG 导出是否都能正确加载该字体。
