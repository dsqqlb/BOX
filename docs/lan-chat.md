# 局域网大厅

路径：`/tools/lan-chat`。这是 BOX 的公共局域网聊天空间：每个有效登录账户都能看到同一份历史消息与附件，不存在好友关系或私聊隔离。

## 功能

- 历史消息按时间分页加载，支持全文搜索；
- 发送文字、图片、视频、音频和普通文件；图片可预览，音视频支持浏览器播放，普通文件可下载；
- 拖拽文件到消息区，或在输入框粘贴图片上传；
- 回复、`@用户名` 提及、表情反应、在线成员和输入中提示；
- 发送者可在两分钟内撤回自己的消息（附件会一并删除）；普通用户没有删除他人或过期消息的权限；
- 管理员可以删除任意消息及附件，并在桌面侧栏查看消息、附件和存储用量。

## 持久化与备份

消息、回复、表情与附件元数据存放在 `data/box.sqlite`；附件二进制存放在 `data/chat/uploads/`。两者必须作为一个整体备份和恢复，否则会出现消息指向缺失附件或磁盘残留文件。

`data/chat/` 是运行时私有数据，已被 Git 忽略，不能提交。默认单文件上限为 1 GiB，可通过环境变量 `CHAT_MAX_UPLOAD_BYTES` 调整；配置值最低 1 MiB、最高 2 GiB（SQLite 附件大小字段的安全上限）。服务账户必须对 `data/chat/uploads/` 有读写权限。

## 安全与网络

所有 `/api/chat/*` 与 `/ws/chat` 请求都要求有效的登录会话和同源来源；文件不会作为公开静态目录提供。下载接口使用随机服务端文件名、附件 ID 查询、`nosniff` 响应头，并对音视频提供 HTTP Range 支持。

局域网并不天然可信。生产或共享网络环境应使用 HTTPS（或置于可信反向代理后），否则文字、附件和会话请求可能被网络中的其他设备窥探。
