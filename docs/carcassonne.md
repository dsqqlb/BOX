# 卡卡颂计分台

路径：`/tools/carcassonne`
所需权限：`carcassonne`

双人卡卡颂桌游的计分工具，原版是一个 JSP/Servlet 小项目（`参考/webDemo`），本页将其重构为 BOX 内的 Next.js 页面，并把存档从 MySQL 改为 SQLite、按账户隔离。

## 界面与操作

- 左右两个半屏分别属于两位玩家（默认“秦”与“马”，顶部名字可直接点击改名）。
- 计分：每名玩家半屏的**右侧**点击 `+1`、长按后连续 `+10`；**左侧**点击 `-1`、长按后连续 `-10`。
- 物品（酒/粮/布）：位于玩家顶部。点击 `+1`，长按连续 `-1`，计数大于 0 时恢复彩色并显示角标。
- 国王/盗贼：位于当前持有方底部。单击 `+1`、长按 `-1`，双击或点 `⇄` 换到对方区域。
- 结算：中间“结算”按钮比较双方酒/粮/布的数量，以及国王/盗贼的持有权；每个优势给对应玩家 `+10`，平手且数量大于 0 时双方都加分，结算后清空全部物品。
- 1D6：中间按钮打开真实 3D D6 骰盘（复用 DND 先攻轮盘的骰子引擎），摇完显示结果，再点一下屏幕关闭。
- 中间“设置”按钮可调节分数数字大小/字体、物品与争夺图案大小、单击与长按步长，以及 1D6 的外观；设置保存在当前浏览器中。
- 争夺方块始终显示原图彩色；单击/长按调整数量，结算时持有方按方块计数加分。

## 数据存储

- 当前分数和计数会持续自动保存在当前浏览器中，刷新后自动恢复（沿用原项目行为）。
- “存档”按钮打开存档面板：`保存当前` 会把整局状态写入 SQLite，同一账户可保存多份；每条可加载或删除。
- 数据表 `CarcassonneSave` 按账户 `ownerId` 隔离，删除账户时级联删除。

## 迁移

从 Java 版本迁移时不需要导入旧 MySQL 数据；如需保留旧记录，可以把 `game_records` 导出后逐条写入 `stateJson`（对应玩家/物品/国王/盗贼字段）。
