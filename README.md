# BOX - 工具箱

一个基于 Next.js 的个人工具集合平台。

## 🚀 快速开始

```bash
# 克隆项目
git clone <repo-url>
cd BOX

# 安装依赖
npm install

# 启动开发服务器（端口 9999）
npm run dev
```

访问 http://localhost:9999

## 🛠️ 现有工具

- **📚 Claude Code 学习中心** - Claude Code 使用指南、指令说明、技巧分享
- **🎲 CSS 骰子模拟器** - D4/D6/D8/D10/D12/D20/D100 骰子模拟（纯 CSS 实现）
- **🏰 DND 语言翻译器** - 中英文互译 + 多种 DND 语言符文显示
